# Rehab motion mark

Original vector concept: an open r, a forward stride, and one sensor node.
The curve suggests supported movement; the detached point references tracking.
The existing lowercase Manrope wordmark stays unchanged.

- Master: `rehab-mark.svg`, transparent background, 32-unit square.
- Color: sage `#47664F`. A single-color silhouette; no gradients or shadows.
- Minimum recommended symbol size: 24 px; app header uses 28 px.
- Keep at least 4 units of external clear space; do not stretch the mark.
- Flutter uses identical native path geometry in `_RehabMark` in `lib/main.dart`.
- Authored for this project; no trademark or exclusivity search has been performed.

Local skill guidance: apple-design (restraint, clarity, small-size craft),
emil-design-eng (optical alignment and cohesive details). No animated logo.
